# Orchiné Studio - Botanical Eco-Print Textures

Designer A pipeline directory for flat 2D eco-print diffuse maps.

## Asset Requirements
- **Resolution:** 2048x2048 square
- **Format:** `.webp` (lossless or 95%+ quality)
- **Mapping:** 1:1 UV square mapping directly onto procedural `PlaneGeometry` scarf surface

## 4 Launch SKU Files
- `solstice.webp` - Eucalyptus & Marigold warm golden botanical imprint
- `fern-whisper.webp` - Bracken & Maidenhair muted forest sage imprint
- `indigo-flora.webp` - Living vat indigo & Japanese maple resist imprint
- `iron-oak.webp` - Oak gall tannin & ferrous acetate dark botanical noir imprint
